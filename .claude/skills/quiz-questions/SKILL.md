# Вопросы для викторины

Пакеты лежат в `quiz/packs/*.json`, к каждому есть CSV-копия для таблиц (`general.csv`, `football.csv`).
Главный пакет — `general.json` («Общие знания»). Подробности о проекте — в `CLAUDE.md` в корне.

## Как добавить вопросы

1. **Посмотри, что уже есть.** Темы пакета и сколько в них вопросов:
   `python3 -c "import json,collections;Q=json.load(open('quiz/packs/general.json'))['questions'];print(collections.Counter(q.get('theme') for q in Q))"`.
   Поищи похожие вопросы по ключевым словам (`grep -i "слово" quiz/packs/general.json`), чтобы не повторяться.
2. **Напиши вопросы** в JSON-файл в scratchpad (не в репозиторий). Формат «один верный»:
   ```json
   [{"q": "Какая страна подарила США статую Свободы?", "right": "Франция",
     "wrong": ["Великобритания", "Испания", "Нидерланды"], "theme": "Страны и города", "level": "normal",
     "answer_image": "media/flags/france.svg",
     "note": "Статую подарили к столетию независимости США; каркас рассчитал Гюстав Эйфель."}]
   ```
   Другие типы — как в пакете: `number` (`answer` — число, `unit`), `text` (`answer` — список вариантов написания),
   `multi`, `order`, `map` (`answer` — [широта, долгота], `place`). Место верного ответа выбирает скрипт.
3. **Добавь:** `python3 .claude/skills/quiz-questions/scripts/add_questions.py <файл.json>`.
   Скрипт сам разложит верные ответы по позициям поровну, скачает смайлики, не пустит чужую тему и повторы.
   Строки «ПРОВЕРЬ, не повтор ли» — прочитай и удали свой вопрос, если это тот же вопрос другими словами.
4. **Проверь и пересобери CSV:** `node .claude/skills/quiz-questions/scripts/check_pack.js` (или `… check_pack.js football`).
5. Перезапусти сервер, сыграй пару вопросов в браузере (экран ведущего и телефон 390×800), затем коммит и PR
   по правилам из `CLAUDE.md` (ветка, описание по-русски, предупреждение «не сливать посреди игры»).

## Правила к каждому вопросу

- **Пояснение** `note` — обязательно: одно-два коротких предложения, почему ответ такой, или интересный факт
  (показывается после ответа у ведущего, на телефонах и в тренировке). Без воды и без повтора вопроса.
- **Без подсказок в тексте.** Прозвища, скобки и уточнения не должны выдавать ответ
  (не «финал 2005 года («стамбульское чудо»)», не «первый спутник» с ответом «Спутник-1»).
- **Тема** — только из уже существующих тем пакета. **Сложность** `level`: `easy`, `normal` или `hard`.
- **Факты.** Знания модели надёжны примерно до середины 2025 года. Всё, что меняется (рекорды, население,
  чемпионы, «самый высокий»), — с датой в тексте: «на 2024 год», «по итогам сезона 2023/24». Сомневаешься — не пиши.
- **Однозначность.** Ровно один верный вариант; неверные — правдоподобные, из той же категории (художники одной
  эпохи, страны одного региона). Без «все ответы верны» и без вариантов-шуток в серьёзных вопросах.
- **Не слишком просто.** Ответ не должен повторять слова вопроса (не «Столица какой страны — Люксембург?»).
- **Вопросы на карте** (`map`) — только в теме «Где на карте».
- **Картинка в вопросе** (`image`) не должна подсказывать ответ — она сама часть вопроса (фото места, блюда, картина).
- **Картинка к ответу** (`answer_image`, показывается после ответа) — желательна у каждого вопроса:
  - ответ — страна: флаг `media/flags/<страна>.svg|png` (флагов Афганистана и Сирии нет — так решил владелец);
  - ответ — человек: портрет из `media/people/` (только общественное достояние);
  - место, планета, картина: `media/places/`, `media/space/`, `media/art/`;
  - иначе объёмный смайлик Microsoft Fluent Emoji: в JSON пиши `"emoji:Название папки"` — названия как на
    github.com/microsoft/fluentui-emoji/tree/main/assets (например `emoji:Red apple`, `emoji:Ear of corn`).
- **Картинки на кнопках ответов** в общих вопросах не ставим (решение владельца).

## Авторские права (репозиторий публичный)

- Можно: свои рисунки кодом (`quiz/tools/make_*.py`), Fluent Emoji (MIT), общественное достояние и CC0
  (Wikimedia Commons, NASA). Источник каждого фото — в `CREDITS.md` его папки.
- Нельзя: чужие фото, кадры из фильмов, логотипы, мелодии современных песен (даже нотами).
- Как скачивать с Wikimedia из этой среды — см. `CLAUDE.md` (адреса upload.wikimedia.org по md5).

## Убрать или поправить вопрос

Правь `quiz/packs/<пакет>.json` (скриптом на Python, сверяя по тексту вопроса), затем `check_pack.js`:
он покажет, если правильные ответы легли неравномерно, и пересоберёт CSV.
