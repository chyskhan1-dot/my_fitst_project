# Памятка для Claude

## О владельце

- Пишет по-русски, новичок в программировании. Отвечать по-русски, просто, по шагам;
  куда нажимать на GitHub и Render — объяснять явно.
- Цель — мобильное приложение-квиз в общем доступе (магазины приложений), с перспективой монетизации
  (бары, корпоративы). Сейчас это сайт на Render; отсюда требования к авторским правам ниже.

## Что в репозитории

- `hello.py`, `index.html` — первые учебные игры «Угадай число» (не трогать без просьбы).
- `quiz/` — основной проект: многопользовательский квиз. Подробности для людей — `quiz/README.md`.
- `render.yaml` — деплой на Render (бесплатный тариф, `rootDir: quiz`, `python server.py`).
  Render сам обновляет сайт после слияния в `main`.

## Устройство `quiz/`

- `server.py` — весь сервер на стандартной библиотеке Python (без зависимостей, так и оставить).
  - Комнаты с 4-значным кодом (`rooms`), ведущий — устройство, создавшее комнату
    (cookie `quiz_device` + `host_token`). Один игрок на устройство; вернуться после вылета
    можно по тому же имени, если прежний игрок не на связи (`OFFLINE_AFTER`). Устройство ведущего
    может быть и игроком: тогда в `play.html` внизу панель управления (`hostBar`, токен из localStorage).
  - `Game` — викторина: этапы `setup → lobby → question → reveal → leaders → … → final`;
    типы вопросов `choice`, `multi`, `order`, `text`, `number` (кто ближе, `best_err`), `map` (точка [широта, долгота],
    `place`, очки по `distance_km`, `MAP_RADIUS`; карта — глобус `static/map.js` (canvas, ортографическая проекция,
    рисуется в браузере, сервер не нагружает) из текстуры `media/map/world-2k.jpg`/`world.jpg` (`tools/make_map.py`,
    данные Natural Earth); правила в `DEFAULTS`,
    фильтр вопросов по `themes` и `levels` (список сложностей; по умолчанию без лёгких — владелец решил) — `Game.pool()`.
    «Раунды по темам» (`rounds`): перед каждыми `ROUND_SIZE`=3 вопросами `topic_vote` (3 темы, голоса с телефонов,
    `/api/vote`) → `topic_bet` (колесо `static/wheel.js`, сектор = 3×голоса+1, победителя выбирает сервер; ставка ×2
    на весь раунд — `/api/bet`, `round_bets`; промах или пропуск при ставке — минус `DOUBLE_LOSS`). Вопросы раунда
    набираются после голосования (`selected` растёт, `target` — сколько всего). Ответ можно пропустить (`skip`, value `None` —
    в списках ответов не считать); правило «Ставка ×2» (`doubles`): `DOUBLES` раза за игру, ошибка — `-DOUBLE_LOSS`. Время на вопрос — `Game.seconds` (`TYPE_TIME`,
    поле вопроса `seconds`). Картинка с эффектом: `image_fx` (`blur`/`zoom`) + `focus`, `fxImg()` в host/play.
    Комментарии к таблице лидеров — `static/comments.js` (общие для ведущего и телефонов).
    «Подлянки» (`sabotage`, по умолчанию вкл., только «каждый за себя»): между вопросами последнее место (`trick_roles()`)
    выбирает, кому кинуть подлянку (любой игрок, по умолчанию лидер — `trick_next.leader`, на телефоне `trickTo`); какая —
    решает случай на сервере, кинувший видит её в `me.trick_sent` (`/api/trick` {to}, `TRICKS`: delay — ответ не раньше `TRICK_DELAY`, сервер
    проверяет; vowels/flip/mirror/fog — портят текст только на телефоне жертвы, кнопки там перемешаны и серые);
    в состоянии `trick_next`/`trick_now`, у игрока `me.can_trick`/`me.trick`/`me.trick_wait`.
    В таблице лидеров у каждого `marks` — как ответил (в раундах — все вопросы раунда), `marks_range()`.
    После вопроса видны ответы всех: `number_answers`/`map_answers` (по точности), `text_answers`, `player_answers`
    (choice/multi/order: сначала верные) — на телефоне `othersAnswers()`, у ведущего — аватарки у вариантов.
  - `FeudEngine` — «100 к 1» (две команды): `fd_round → fd_play → [fd_steal] → fd_reveal` × 4 раунда
    (простая, двойная, тройная, наоборот) → `fd_big_intro → fd_big_q × 5 → fd_big_result → final`.
  - `SiEngine` — «Своя игра»: `si_round → si_board → [si_cat_give|si_stake] → si_question ⇄ si_answer
    → si_reveal … → si_final_bet → si_final_q → si_final_reveal → final`.
    Пакет по умолчанию `SI_AUTO` — `si_from_quiz()`: случайное табло из тем `general` на каждую игру
    (`SI_ROUNDS`, вопросы — `si_answers()`; `"si": false` у вопроса — не брать; сыгранные — `Game.si_used`).
  - Проверка текстовых ответов: `text_matches` (транслитерация по «звучанию», опечатки, фамилия
    без имени), для «Своей игры» — `si_match` (плюс варианты из `answer_variants`).
  - Клиенты опрашивают `/api/state` каждые 0,5–0,7 с, но не больше одного запроса за раз
    (`poll`/`pollOnce`, обрыв через 5 с, «Нет связи» — после 3 неудач подряд); ответ на запрос, отправленный
    до входа (`pid` сменился, пока он шёл), телефон отбрасывает — иначе вошедшего выкидывает обратно на форму; `VERSION` — хэш
    файлов: открытые страницы сами перезагружаются после деплоя.
- Статистика для владельца: `Stats`/`STATS` в server.py (только счётчики, в памяти), страница
  `static/stats.html` по `/stats?key=` (`STATS_KEY` из окружения, в render.yaml — `generateValue`).
- `siq.py` — чтение пакетов SIGame (`.siq`, zip с `content.xml`, обе версии разметки).
- `static/host.html` — экран ведущего (ТВ), `static/play.html` — главная/телефон игрока,
  `static/editor.html` — редактор пакетов, `static/pack.js` — чтение CSV/JSON и картинок,
  `static/music.js` — синтезированная музыка (Web Audio, без файлов). Звук на телефонах (`play.html`): телефон
  ведущего-игрока (`speaker()` = есть host_token) играет как экран ведущего (`soundtrack()`), остальные молчат —
  мелодию вопроса можно включить кнопкой «Послушать здесь» (`listen()`). iPhone: `navigator.audioSession.type =
  "playback"`, иначе беззвучный переключатель глушит звук; скрытая вкладка — музыка на паузе.
- `packs/*.json` — пакеты викторины (`general.csv`, `football.csv` — копии для таблиц); футбол — и отдельный квиз `football.json`
  (временно, решение владельца), и тема «Футбол» в `general.json`: правят `football.json`, потом копируют скриптом
  `.claude/skills/quiz-questions/scripts/sync_football.py`; флаги и столицы —
  темы внутри `general.json`; простые флаги рисует `tools/make_flags.py` (SVG), флаги с гербами — PNG с Wikimedia Commons
  (владелец разрешил; источники — `media/flags/CREDITS.md`). Нет флагов Афганистана и Сирии (спорные/сменились).
  Выбор вопросов в игре — `balanced_sample()`: поровну из каждой темы. Картинки к вопросам: `media/signs/`
  (знаки и светофоры, рисует `tools/make_signs.py`), `media/count/` — картинки «На внимательность» (`tools/make_count.py` рисует и считает ответы), `media/pics/` — Microsoft Fluent Emoji (MIT, `media/pics/LICENSE`,
  брать с GitHub `microsoft/fluentui-emoji`, папки `3D`). Картинка не должна подсказывать ответ — она сама вопрос.
  Поле `note` — пояснение к ответу (есть у всех вопросов `general`; CSV-колонка «Пояснение»; host/play/learn, редактор;
  в автопереходе показ ответа длится дольше, если есть пояснение). Поле `answer_image` — картинка к ответу (после ответа: host/play/learn, редактор, колонка CSV `Картинка к ответу`):
  флаг, если ответ — страна; портрет, если человек (`media/people/`, только общественное достояние);
  иначе Fluent Emoji (`media/pics/ans-*.png`). Поле `option_images` — картинки к вариантам (CSV-колонка
  «Картинки к вариантам» через « | ») — только для своих пакетов: владелец решил в общих вопросах картинки на кнопки
  не ставить (картинка — в самом вопросе). Фигурок ▲◆●■ у вариантов нет — различаются цветом. На карточках пакетов
  число вопросов не показываем (владелец решил). Картинка к ответу: фото/портрет/флаг — крупно (`.photo`), смайлик — меньше. `media/chem/` — таблица Менделеева и клетки элементов
  (`tools/make_chem.py`; в таблице без номеров — иначе подсказка к «Сколько элементов?»).
  `media/art/` — картины (общественное достояние, Wikimedia Commons; источники — `media/art/CREDITS.md`),
  `media/space/` — снимки NASA (общественное достояние; `media/space/CREDITS.md`), `media/places/` — фото мест
  к вопросам «Где на карте» (только PD/CC0; `media/places/CREDITS.md`).
  Wikimedia из этой среды: API (`commons.wikimedia.org/w/api.php`) часто отвечает 429, а `thumb.wikimedia.org`
  закрыт — файлы брать напрямую с `upload.wikimedia.org/wikipedia/commons/thumb/<md5[0]>/<md5[:2]>/<Имя>/960px-<Имя>`
  (md5 от имени файла с «_» вместо пробелов; размеры только стандартные: 500, 960, 1280).
  Смайлики (аватарки, ребусы, метки на карте) рисуются картинками: `QuizEmoji.html()` из `static/emoji.js`, файлы —
  `media/emoji/<коды>.webp` (WebP — в 5 раз легче PNG); новые смайлики в `AVATARS` или ребусах — докачать `tools/fetch_emoji.py`.
  Правила ведущего запоминаются на устройстве (`quiz-rules` в localStorage, `savedRules()`/`saveRules()` в host.html).
  Телефон перерисовывает экран целиком; если этап тот же (`lastScene`), анимации появления отключены (`#main.calm`),
  а `render()` (обёртка над `draw()`, и в host.html) держит прокрутку на месте. В лобби телефона — список игроков.
  Кнопки форм на телефоне срабатывают по касанию (`pointerdown` в play.html) — иначе клавиатура сдвигает экран и нажатие теряется.
- Установка значком на телефон (PWA): `static/manifest.webmanifest` и `static/sw.js` (сервер отдаёт их с корня сайта;
  сервис-воркер трогает только открытие страниц — без сети показывает «Нет связи», ничего не кэширует),
  иконки — `media/app/` (рисует `tools/make_icon.js`, Playwright). На главной `play.html` кнопка «📲 Установить на телефон»:
  Android — системное окно (`beforeinstallprompt`), iPhone — подсказка про «На экран „Домой“»; в установленном приложении скрыта.
- `static/learn.html` — тренировка (`/learn`): один игрок, свой ответ проверяет `POST /api/learn/text`,
  прогресс — в localStorage (`quiz-learn`). Владелец решил: тренировка только по странам — в меню лишь
  подборки `COLLECTIONS` («Страны мира» = темы Флаги/Столицы/Страны и города из `general`).
  `si/*.json|*.siq` — пакеты «Своей игры», `feud/*.json` — пакеты «100 к 1» (`basic.csv` — копия
  для таблиц), `media/` — картинки к пакетам.

## Как проверять изменения

- Синтаксис: `python3 -c "import ast;ast.parse(open('quiz/server.py').read())"`.
- Запуск: `cd quiz && python3 server.py` (порт 8000) — фоном.
- Останавливать только так: `pkill -f "[s]erver\.py"` — без скобок команда убивает собственную оболочку.
- API-тесты — Python + `urllib` с `http.cookiejar` (у каждого «игрока» свой cookie).
- Браузер — Playwright из `npm root -g`, Chromium с `--autoplay-policy=no-user-gesture-required`.
  Проверять и экран ведущего, и телефон (390×800), смотреть скриншоты, ловить `pageerror`.
- После любой правки прогонять заново и старые сценарии: комнаты, типы вопросов, редактор,
  музыкальный раунд, «Своя игра», «100 к 1». Тестовые скрипты держать в scratchpad, не в репозитории.
- Звук на слух проверить нельзя — честно говорить об этом.

## Договорённости

- **Авторские права.** Не класть в репозиторий (он публичный) чужие фото, музыку, мелодии
  современных песен даже нотами. Мелодии — только общественное достояние. Пакет `.siq`
  владельца (с фото знаменитостей и OST) в репозиторий не добавлен — он загружает его в меню.
- **Факты.** Знания модели надёжны примерно до середины 2025 года; вопросы со статистикой
  привязывать к дате в тексте («по итогам сезона 2023/24»). Проверять варианты на однозначность.
- **Пакеты.** Правильные ответы раскладывать по позициям поровну; CSV и JSON держать в
  соответствии (проверка через `pack.js` в Node). Каждому новому вопросу ставить `theme`
  из уже существующих тем пакета (задел: собирать из тем раунды «Своей игры») и `level`.
  Вопросы `map` — только в теме «Где на карте» (в «Своей игре» и тренировке их не сыграть).
- **Тексты интерфейса** — по-русски, коротко, без лишних слов. Стиль кода — как в существующих файлах.
- **Git.** Работа в ветке `claude/elegant-fermat-wwpsqn`; каждую порцию изменений — отдельным
  Pull Request в `main`, сливает владелец. Если прошлый PR уже слит — сначала подтянуть `main`.
  Предупреждать: не сливать посреди игры (сервер перезапустится, игры пропадут).
- **Ограничения Render free:** засыпает через 15 минут, ~512 МБ памяти, игры и загруженные
  пакеты живут только в памяти.
