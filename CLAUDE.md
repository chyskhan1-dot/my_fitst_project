# Памятка для Claude

## О владельце

- Пишет по-русски, новичок в программировании. Отвечать по-русски, просто, по шагам;
  куда нажимать на GitHub и Render — объяснять явно.
- Цель — квиз-платформа для компании друзей с перспективой монетизации
  (бары, корпоративы). Отсюда требования к авторским правам ниже.

## Что в репозитории

- `hello.py`, `index.html` — первые учебные игры «Угадай число» (не трогать без просьбы).
- `quiz/` — основной проект: многопользовательский квиз. Подробности для людей — `quiz/README.md`.
- `render.yaml` — деплой на Render (бесплатный тариф, `rootDir: quiz`, `python server.py`).
  Render сам обновляет сайт после слияния в `main`.

## Устройство `quiz/`

- `server.py` — весь сервер на стандартной библиотеке Python (без зависимостей, так и оставить).
  - Комнаты с 4-значным кодом (`rooms`), ведущий — устройство, создавшее комнату
    (cookie `quiz_device` + `host_token`). Один игрок на устройство; вернуться после вылета
    можно по тому же имени, если прежний игрок не на связи (`OFFLINE_AFTER`).
  - `Game` — викторина: этапы `setup → lobby → question → reveal → leaders → … → final`;
    типы вопросов `choice`, `multi`, `order`, `text`; правила в `DEFAULTS`.
  - `FeudEngine` — «100 к 1» (две команды): `fd_round → fd_play → [fd_steal] → fd_reveal` × 4 раунда
    (простая, двойная, тройная, наоборот) → `fd_big_intro → fd_big_q × 5 → fd_big_result → final`.
  - `SiEngine` — «Своя игра»: `si_round → si_board → [si_cat_give|si_stake] → si_question ⇄ si_answer
    → si_reveal … → si_final_bet → si_final_q → si_final_reveal → final`.
  - Проверка текстовых ответов: `text_matches` (транслитерация по «звучанию», опечатки, фамилия
    без имени), для «Своей игры» — `si_match` (плюс варианты из `answer_variants`).
  - Клиенты опрашивают `/api/state` каждые 0,5–0,7 с; `VERSION` — хэш файлов: открытые
    страницы сами перезагружаются после деплоя.
- `siq.py` — чтение пакетов SIGame (`.siq`, zip с `content.xml`, обе версии разметки).
- `static/host.html` — экран ведущего (ТВ), `static/play.html` — главная/телефон игрока,
  `static/editor.html` — редактор пакетов, `static/pack.js` — чтение CSV/JSON и картинок,
  `static/music.js` — синтезированная музыка (Web Audio, без файлов).
- `packs/*.json` — пакеты викторины (`football.csv`, `school.csv` — копии для таблиц),
  `si/*.json|*.siq` — пакеты «Своей игры», `feud/*.json` — пакеты «100 к 1» (`basic.csv` — копия
  для таблиц), `media/` — картинки к пакетам.

## Как проверять изменения

- Синтаксис: `python3 -c "import ast;ast.parse(open('quiz/server.py').read())"`.
- Запуск: `cd quiz && python3 server.py` (порт 8000) — фоном.
- Останавливать только так: `pkill -f "[s]erver\.py"` — без скобок команда убивает собственную оболочку.
- API-тесты — Python + `urllib` с `http.cookiejar` (у каждого «игрока» свой cookie).
- Браузер — Playwright из `npm root -g`, Chromium с `--autoplay-policy=no-user-gesture-required`.
  Проверять и экран ведущего, и телефон (390×800), смотреть скриншоты, ловить `pageerror`.
- После любой правки прогонять заново и старые сценарии: комнаты, типы вопросов, редактор,
  музыкальный раунд, «Своя игра», «100 к 1». Тестовые скрипты держать в scratchpad, не в репозитории.
- Звук на слух проверить нельзя — честно говорить об этом.

## Договорённости

- **Авторские права.** Не класть в репозиторий (он публичный) чужие фото, музыку, мелодии
  современных песен даже нотами. Мелодии — только общественное достояние. Пакет `.siq`
  владельца (с фото знаменитостей и OST) в репозиторий не добавлен — он загружает его в меню.
- **Факты.** Знания модели надёжны примерно до середины 2025 года; вопросы со статистикой
  привязывать к дате в тексте («по итогам сезона 2023/24»). Проверять варианты на однозначность.
- **Пакеты.** Правильные ответы раскладывать по позициям поровну; CSV и JSON держать в
  соответствии (проверка через `pack.js` в Node).
- **Тексты интерфейса** — по-русски, коротко, без лишних слов. Стиль кода — как в существующих файлах.
- **Git.** Работа в ветке `claude/elegant-fermat-wwpsqn`; каждую порцию изменений — отдельным
  Pull Request в `main`, сливает владелец. Если прошлый PR уже слит — сначала подтянуть `main`.
  Предупреждать: не сливать посреди игры (сервер перезапустится, игры пропадут).
- **Ограничения Render free:** засыпает через 15 минут, ~512 МБ памяти, игры и загруженные
  пакеты живут только в памяти.
