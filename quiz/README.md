# Квиз для друзей

Ведущий показывает вопросы на большом экране, игроки отвечают с телефонов.
Нужен только Python 3, без дополнительных библиотек.

## Запуск дома (через Wi-Fi)

```bash
cd quiz
python server.py
```

Сервер напишет две ссылки:

- **экран ведущего** (`http://localhost:8000/host?key=...`) — открой на ноутбуке или телевизоре;
- **для игроков** (`http://192.168.x.x:8000`) — друзья открывают на телефонах в том же Wi-Fi.

Если Windows спросит про брандмауэр, разреши доступ для частных сетей.

## Запуск онлайн (Render.com, бесплатно)

1. Зарегистрируйся на https://render.com через GitHub.
2. **New → Blueprint**, выбери этот репозиторий. Render найдёт файл `render.yaml`.
3. После запуска сайт будет по адресу вида `https://quiz-xxxx.onrender.com`.
4. Ключ ведущего: в Render открой сервис → **Environment** → `HOST_KEY`.
   Экран ведущего: `https://quiz-xxxx.onrender.com/host?key=ТВОЙ_КЛЮЧ`.

На бесплатном тарифе сервер засыпает через 15 минут без игроков,
первое открытие после этого занимает около минуты.

## Главное меню и правила

Экран ведущего открывается с главного меню. В нём выбирается тип игры (пока готова
только «Викторина», «Своя игра» и «100 к 1» в разработке) и правила:

- **командная игра** — 2, 3 или 4 команды; игрок выбирает команду на телефоне,
  счёт команды — средний по её игрокам;
- **штраф за ошибку** — минус 300 очков за неверный ответ (ниже нуля не опускается);
- **бонус за скорость** — от 500 до 1000 очков, без него всегда 1000;
- **бонус за серию** — +100 за каждый правильный ответ подряд, до +500;
- **перемешать вопросы** и **перемешать варианты ответов**;
- **таблица лидеров** после каждого вопроса;
- **время на ответ** — 10, 20 или 30 секунд.

Игроки могут подключаться, пока ведущий выбирает правила.

## Свои вопросы

Открой `questions.json`. У каждого вопроса: текст `q`, варианты `options`
и номер правильного ответа `answer` (считаем с нуля: 0 — первый вариант).
`seconds` — время на ответ. После изменений перезапусти сервер.
