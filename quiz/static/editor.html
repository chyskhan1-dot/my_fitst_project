Редактор вопросов

Вопросы можно писать здесь или подготовить в Google Таблицах / Excel: колонки Вопрос · Вариант 1–4 · Правильный (1–4) · Картинка · Аудио, затем «Файл → Скачать → CSV» и «Открыть файл» здесь. Скачать шаблон таблицы.

Где хранить пакет • На один вечер: кнопка «Играть с этим пакетом» внизу. Пакет живёт, пока открыта комната. • Навсегда: «Скачать .json» и загрузи файл на GitHub в папку quiz/packs (на сайте GitHub: Add file → Upload files). После обновления сервера пакет появится в меню у всех. • Картинки и аудио, загруженные с компьютера, сохраняются прямо в файле пакета. Картинки уменьшаются автоматически, аудио — до 8 МБ на вопрос, весь пакет — до 25 МБ.
