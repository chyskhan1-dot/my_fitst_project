# Проверки

Запуск всех проверок из папки `quiz`: `bash tests/run_all.sh` (нужны Python 3, Node и Playwright с Chromium).

- `t_*.py` — проверки сервера по API: очки, режимы, перки, память вопросов, аудит (`t_audit.py`: перемешивание вариантов,
  «кто ближе», лимиты, возврат игрока), случайные действия во всех режимах (`t_fuzz.py`).
- `b_*.js` — проверки в браузере (экран ведущего 1280×720 и телефоны): гора, подлянки, реакции, порядок, «Слово на лбу»,
  «случайный игрок» во всех режимах (`b_monkey.js`), экраны телефона для проверки дизайна (`b_audit.js`).

После любой правки запускать всё; новые проверки класть сюда же.
